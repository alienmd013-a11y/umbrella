# umbrella
Проект в рамках программы "управление высокотехнологичными продуктами" от Факультета Прикладной Математики и Информатики МФТИ 2024. В рамках проекта была разработана бизнес модель проекта, реализованы приложение (при моем участии) и прототип установки. В рамках куса освоены такие темы как unit-экономика, продуктовый и проектный маркетинг, в рамках проекта был произведен таргетный анализ спроса целевой аудитории (студентов), проведена работа со статикой полученной из опросов для обоснованного расчета продуктовых и проектных метрик представленных в презентации.
